STYLE GUIDE

Sudoku Fighting — visual design reference & component inventory

Organized by Atomic Design: Foundations → Atoms → Molecules → Organisms → Templates. Each level builds on the previous and introduces no new visual primitives. React migration path: foundations → theme/token files; atoms/molecules/organisms → component files; templates → screen layout files.

Naming Principle

Components are named for the pattern, not the use case. A component should start with its most abstract, reusable identity. The current instance — where it appears, what it contains — lives in the consuming screen or its props, not in the component's own name or class.

Wrong — named for use case
SettingsPanel → only makes sense as a settings menu
.join-combo → implies room-joining, can't be reused
.lobby-status → tied to lobby screen context
Right — named for pattern
ContextualMenu → any dark floating control panel
.combo-input → any fused input + action button
.status-pill → any semantic state label

When you find yourself naming a component after where it lives (LobbyHeader, GameButton, SettingsPanel), stop and ask: what is the shape of this thing? Name that instead. The specific context belongs to the parent.

The Mid-Dark Rule

When white text appears with a player-color shadow, use the mid-dark variant (p1-mid-dark, p2-mid-dark), not the primary color. The primary cyan and magenta are too bright for a shadow — they'd feel garish. The mid-dark is dark enough to read as a grounding shadow while still being clearly player-colored.

Icons

SVG assets from /assets/ui/. Use currentColor for stroke so they inherit color from the parent element. On React Native, platform-specific icon sets should live in /assets/icons/native/ to allow conditional imports.

chevron-left
chevron-right
settings (inline SVG)
Usage
Chevrons: /assets/ui/chevron-left.svg, chevron-right.svg — stroke-based with currentColor. Must be inlined as <svg> (not <img>) to inherit the parent element's color — <img> isolates the SVG's rendering context and breaks currentColor.

Settings gear: inline SVG in HTML (no separate file yet). Fill-based.

React Native: Replace <img> with <Image> or an icon component that maps name → platform asset. Store as assets/icons/web/ and assets/icons/native/ for platform-specific variants.
ATOMS

Smallest indivisible pieces. No internal composition. Maps to primitive component files in React.

Buttons

All buttons use Roboto Mono, 700 weight. Press interaction: translate +2px/+2px with shadow shrink. Release: translate -1px/-2px with shadow grow. Shadow is a hard pixel offset (no blur) — the direction and color are the meaningful signals.

Usage
Primary action on each screen: Quick Play, Create Room, Select character, Play Again.

Alternate Primary — .btn.btn-alt

Usage
A second primary-weight CTA when a screen already has a .btn primary and a second primary-weight action is needed alongside it. Currently: VS AI on the start screen, START! in the SP lobby. Only use when two primary CTAs must coexist — if there is a single primary action, always use .btn (purple).

Destructive — .btn.btn-danger

Usage
Any action that destroys or irreversibly exits. Currently: Leave at game-over overlay. Semantic contract: if it deletes, exits, or can't be undone, use this class.

Grid Borders & Box Dividers

Thin cell lines: 1px #D5D5D5. Thick 3×3 box dividers: 2px #888888. Own grid: 3px in player color. Right and bottom borders adjacent to box lines are suppressed to prevent double-border artifacts.

Layer stack (back to front)
Arena background image
Sun + midground graphics (palms, buildings)
Fight stage — character sprites (P1 left, P2 right flipped)
HUD organism — health bars, names, timer, scores, combo
Sudoku Grid organism × 2 — P1 left panel, P2 right panel
Mobile Numpad molecule — touch devices only
Game Overlay organism — FIGHT!/KO/VICTORY/DEFEAT (conditional)
Contextual Menu organism — triggered by settings icon
Attack flash — full-screen inset shadow effect
Notes
Arena background is set by JS from the selected arena config.
Surrender button lives in the action bar row at top-right, uses .btn-utility.
Numpad is hidden on desktop via @media (pointer: fine).
Overlay visibility is toggled by JS — never display:none mid-game to avoid reflow.
